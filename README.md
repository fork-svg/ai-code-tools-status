# AI Code Completion Tools Status

> Last updated: 2025-01-15

## ⚠️ Major Changes in 2024-2025

The AI code completion landscape has undergone significant consolidation. Many previously popular standalone tools have been acquired or discontinued.

---

## 📊 Tool Status Overview

| Tool | Status | What Happened |
|------|--------|---------------|
| **Codeium** | ❌ **Discontinued** | Rebranded to Windsurf in April 2025, then acquired by Cognition (Devin) in July 2025 |
| **Windsurf** | 🔄 **Acquired** | Now owned by Cognition AI (Devin team) |
| **Supermaven** | ❌ **Sunset** | Acquired by Cursor in November 2024, standalone product being phased out |
| **Tabnine** | ✅ **Active** | Still independent, launched "Tabnine Agentic" features |
| **GitHub Copilot** | ✅ **Active** | Microsoft's offering, still market leader |
| **Cursor** | ✅ **Active** | AI-native IDE, absorbed Supermaven's tech |
| **Claude Code** | ✅ **Active** | Anthropic's CLI-based coding assistant |
| **Amazon Q Developer** | ✅ **Active** | AWS's enterprise-focused assistant |
| **JetBrains AI** | ✅ **Active** | Native JetBrains IDE integration |

---

## 🕰️ Timeline of Changes

### 2024
- **November 2024**: Cursor acquires Supermaven

### 2025
- **April 2025**: Codeium officially rebrands to Windsurf

## 📝 Detailed Tool Information

### Tabnine
- **Status**: ✅ Active & Independent
- **Website**: https://tabnine.com
- **Free Tier**: Yes (limited)
- **Pro**: $12/user/month
- **Enterprise**: Custom pricing
- **Key Features**:
  - Multiple AI models (GPT-4, Claude, local models)
  - SOC 2 Type 2 certified
  - Air-gapped deployment option
  - "Tabnine Agentic" workflow automation (new)
- **IDE Support**: VS Code, JetBrains, Visual Studio, Vim/Neovim

### Cursor
- **Status**: ✅ Active
- **Website**: https://cursor.sh
- **Type**: AI-native IDE (VS Code fork)
- **Free Tier**: Limited
- **Pro**: $20/month
- **Key Features**:
  - Integrated Supermaven tech (acquired Nov 2024)
  - Chat + inline completions
  - Multi-file editing
  - "Composer" for multi-file generation
- **Note**: Not a plugin, full IDE replacement

### Claude Code
- **Status**: ✅ Active
- **Provider**: Anthropic
- **Type**: CLI tool
- **Pricing**: Usage-based via Anthropic API
- **Key Features**:
  - Terminal-based workflow
  - Codebase-aware suggestions
  - Git integration
  - Works with any editor

### GitHub Copilot
- **Status**: ✅ Active
- **Provider**: GitHub/Microsoft
- **Free Tier**: Yes (limited monthly completions)
- **Pro**: $10/month
- **Business**: $19/user/month
- **Key Features**:
  - Chat + inline completions
  - Workspace awareness
  - Multiple model support (GPT-4o, Claude 3.5 Sonnet, Gemini)
  - Agent mode (in preview)

### Amazon Q Developer
- **Status**: ✅ Active
- **Provider**: AWS
- **Free Tier**: Yes (limited)
- **Pro**: $19/user/month
- **Key Features**:
  - Deep AWS service integration
  - Code transformation (Java 8→17, etc.)
  - Security scanning
  - Chat-based development

## 🚫 Discontinued/Changed Tools

### Codeium
- **Original**: Free AI code completion for 40+ IDEs
- **Rebranded to**: Windsurf (April 2025)
- **Then acquired by**: Cognition AI / Devin (July 2025)
- **Legacy users**: Migrate to Windsurf plugins or alternative tools

### Supermaven
- **Original**: Fast AI completion with 1M token context
- **Acquired by**: Cursor (November 2024)
- **Status**: Standalone product being sunset
- **Migration**: Technology integrated into Cursor

### Windsurf
- **Original**: Rebrand of Codeium (April 2025)
- **Acquired by**: Cognition AI (July 2025)
- **Current status**: Being integrated into Devin ecosystem
